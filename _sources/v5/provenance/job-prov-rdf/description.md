# Job Provenance - PROV-O RDF (Turtle, N-Triples)

Media type: `text/turtle, application/n-triples`.

PROV-O RDF representation of the Job Provenance Response, as Turtle (text/turtle) and N-Triples (application/n-triples).

This block is a profile of the Job Provenance Response (`ogc.api.processes.v5.responses.jobProv`) and implements the `ogc.ogc-utils.prov.w3c-prov-rdf` format of `bblocks-prov-jsonld-alt`.
