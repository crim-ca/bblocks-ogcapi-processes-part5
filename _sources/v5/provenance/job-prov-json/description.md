# Job Provenance - PROV-JSON (application/provenance+json)

Media type: `application/provenance+json (alias application/json)`.

PROV-JSON representation of the Job Provenance Response. Default and mandatory format of GET /jobs/{jobId}/prov.

This block is a profile of the Job Provenance Response (`ogc.api.processes.v5.responses.jobProv`) and implements the `ogc.ogc-utils.prov.w3c-prov-json` format of `bblocks-prov-jsonld-alt`.
